# Prompt: เขียนบทเล่า "ทำไมหัวข้อนี้ emerging" (emerging narrative)

> **สถานะ: ออกแบบไว้ล่วงหน้า — ยังไม่ implement** (ดู ROADMAP §ข้อ 8)
> เมื่อ implement: แนะนำทำเป็น step `narrative` หลัง `emerging` ส่งเฉพาะ top N emerging ให้ LLM
> เขียนผลลง `narrative_th`/`narrative_en` ใน export → เว็บแสดงใต้กราฟในแผง detail

## บริบทการใช้

ผู้บริหารเห็นตัวเลขแล้วมักถาม "แล้วมันคืออะไร ทำไมถึงโต" — prompt นี้ให้ LLM แปลง metric ดิบ
เป็นย่อหน้าสั้นที่คนไม่ใช่ data scientist อ่านรู้เรื่อง โดยห้ามเดาเกินข้อมูลที่ให้

## Prompt (master)

```
คุณคือนักวิเคราะห์นโยบายวิจัย ช่วยเขียนคำอธิบายหัวข้อวิจัยที่ "กำลังเกิดใหม่" สำหรับผู้บริหาร

ข้อมูลหัวข้อ:
- ชื่อ: {name_th} ({name_en})
- คำสำคัญ: {keywords}
- คำอธิบายหัวข้อ: {description}

ตัวเลข (ค.ศ.):
- สัดส่วนบทความช่วง {baseline_years}: {share_baseline} → ช่วง {recent_years}: {share_recent} (โตกว่าภาพรวม {share_ratio} เท่า)
- อัตราโตเฉลี่ยช่วง 3 ปีล่าสุด: {cagr_pct}% ต่อปี
- ช่วงที่จำนวนบทความ "ระเบิด": {burst_years}
- จำนวนบทความ 3 ปีล่าสุด: {count_recent} เรื่อง

ตัวอย่างชื่อบทความจริงในหัวข้อนี้:
{titles}

เขียน 2–3 ประโยคภาษาไทย โดย:
1. บอกว่าหัวข้อนี้เกี่ยวกับอะไร (จากชื่อ/คำสำคัญ/ตัวอย่างบทความ)
2. บอกสัญญาณการเติบโตจากตัวเลข (เลือก 1–2 ตัวเลขที่น่าสนใจสุด)
3. หากตัวอย่างบทความบอกบริบทได้ (เช่น นโยบาย วิกฤต เทคโนโลยีใหม่) ให้เชื่อมโยง — แต่ห้ามเดาเกินข้อมูล

ห้าม: ใช้คำว่า "น่าสนใจ" "สำคัญมาก" หรือคำฟู่ ทุกข้อเท็จจริงต้องมาจากข้อมูลข้างต้น
ตอบเฉพาะย่อหน้าคำอธิบาย ไม่ต้องมีหัวข้อหรือ JSON
```

## หมายเหตุการ implement

- ค่าใช้จ่าย: top 24 emerging × ~500 token ≈ น้อยมากต่อรอบ
- ควร cache ด้วย prompt_hash เหมือน label.py
- เว็บ: เพิ่มฟิลด์ `narrative_th`/`narrative_en` (optional) ใน `AtlasNode` → แสดงเหนือกราฟ forecast ใน DetailPanel
