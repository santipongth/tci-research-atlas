# Prompt: บันทึกวิธีวิจัยของหัวข้อ (topic methods note)

> **สถานะ: ใช้งานเมื่อ `methods.provider: llm` เท่านั้น (ค่าเริ่มต้น off) — ไฟล์นี้คือต้นฉบับเดียว** `pipeline/atlas/methods.py` อ่าน block ใต้ "Prompt (master)" ตอนรัน (งาน LLM `methods`)
> แก้ข้อความใน block = `prompt_version` เปลี่ยน → บันทึกถูกเขียนใหม่ในรอบถัดไป; แก้หมายเหตุนอก block ไม่มีผลต่อ cache

## บริบทการใช้

- เรียกต่อหัวข้อ (ระดับหัวข้อเท่านั้น — ไม่เคยส่งบทคัดย่อรายบทความ) เฉพาะ `methods.note_top_n` หัวข้อที่มีบทความมากที่สุดใน `work/12_methods_topics`
- inputs: `{facts}` = ตัวเลขจากคลังคำวิธีวิจัย (จำนวนบทความในช่วง, สัดส่วนที่ระบุวิธีได้, 5 วิธีที่พบบ่อย, มัธยฐานขนาดตัวอย่าง, สัดส่วน "แบบสอบถาม + สถิติพรรณนาอย่างเดียว") · `{titles}` = ชื่อบทความในหัวข้อ (บรรทัดละ 1 เรื่อง)
- **ตรวจหลังได้คำตอบ** (`narrative.grounding_error`): ตัวเลขทุกตัวต้องอยู่ใน `{facts}` และห้ามมีชื่อหัวข้ออื่น → ไม่ผ่าน = เขียนใหม่ `llm.max_regenerations` ครั้ง → ไม่ผ่านอีก = ประโยคแม่แบบจากตัวเลขชุดเดียวกัน (`source: template`)
- ผลลัพธ์ → `work/12_methods_notes` → `methods.json → topics[].note` (เว็บแสดงพร้อมป้าย "สรุปอัตโนมัติจากตัวเลขของระบบ")

## Prompt (master)

```
คุณคือที่ปรึกษาด้านระเบียบวิธีวิจัย เขียนบันทึกสั้นเรื่องวิธีวิจัยที่ใช้ในหัวข้อวิจัยหนึ่งหัวข้อ สำหรับบรรณาธิการวารสารและนักวิจัย

ข้อเท็จจริงจากระบบ (ใช้ได้เฉพาะข้อมูลนี้):
{facts}

ตัวอย่างชื่อบทความในหัวข้อนี้:
{titles}

เขียน 1–2 ประโยค เป็นภาษาไทยและภาษาอังกฤษที่ความหมายตรงกัน โดย:
1. บอกวิธีวิจัยที่พบบ่อยที่สุด พร้อมตัวเลข 1–2 ตัวจากข้อเท็จจริง
2. ถ้าข้อเท็จจริงบอกว่าบทความจำนวนมากใช้เฉพาะแบบสอบถามและสถิติพรรณนา ให้บอกตรง ๆ โดยไม่ตัดสินคุณภาพ

กติกา:
- ตัวเลขทุกตัวต้องมาจากข้อเท็จจริงข้างต้น (ปัดเศษได้) ห้ามคำนวณตัวเลขใหม่ ห้ามแปลงปีเป็น พ.ศ.
- ห้ามเอ่ยชื่อหัวข้ออื่น ห้ามเอ่ยชื่อบุคคลหรือสถาบัน ห้ามแนะนำวิธีที่ข้อมูลไม่ได้บอก

ตอบกลับเป็น JSON เท่านั้น ห้ามมีข้อความอื่น:
{
  "th": "บันทึกภาษาไทย",
  "en": "The same note in English"
}
```
