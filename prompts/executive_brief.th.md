# Prompt: บทสรุปผู้บริหาร (executive brief)

> **สถานะ: ใช้งานจริง — ไฟล์นี้คือต้นฉบับเดียว** `pipeline/atlas/narrative.py` อ่าน block ใต้ "Prompt (master)" ตอนรัน (งาน LLM `brief`)
> แก้ข้อความใน block = `prompt_version` เปลี่ยน → บทสรุปถูกเขียนใหม่ในรอบถัดไป; แก้หมายเหตุนอก block ไม่มีผลต่อ cache

## บริบทการใช้

- เรียก 1 ครั้งต่อรอบข้อมูล — ผลคือ headline ของหน้า Overview (ประโยคแบบบทบรรณาธิการเหนือ forest plot) และ bullet สั้นสำหรับ PDF brief
- inputs: `{facts}` = ช่วงปีที่วิเคราะห์ (และปีที่ยังไม่ครบ), จำนวนบทความ/หัวข้อ, จำนวนหัวข้อตามสถานะ, 3 หัวข้อแรกของ EMERGING / HOT / DECLINING พร้อมจำนวนบทความและอัตราเปลี่ยนพร้อมช่วงเชื่อมั่น
- **ตรวจหลังได้คำตอบ** เหมือน topic narrative: ตัวเลขทุกตัวต้องอยู่ใน `{facts}`, ชื่อหัวข้อต้องเป็นชื่อที่อยู่ใน `{facts}` เท่านั้น; เลขลำดับหน้า bullet ถูกตัดก่อนตรวจ → ไม่ผ่าน = เขียนใหม่ → ไม่ผ่านอีก = แม่แบบ (`source: template`)
- ผลลัพธ์ → `work/11_brief.json` → `overview.json → brief`
- น้ำเสียง (ตั้งแต่ web refresh 2026-10-23): ภาษาง่ายสำหรับประชาชนทั่วไป เริ่มด้วยตัวอย่าง ชื่อสถานะภาษาไทย ห้ามศัพท์สถิติตามรายการใน prompt

## Prompt (master)

```
คุณคือนักวิเคราะห์นโยบายวิจัย เขียนบทสรุปของแผนที่งานวิจัยไทยรอบนี้ ให้ประชาชนทั่วไปและผู้บริหารอ่านเข้าใจในครั้งเดียว

ข้อเท็จจริงจากระบบ (ใช้ได้เฉพาะข้อมูลนี้):
{facts}

เขียนเป็นภาษาไทยและภาษาอังกฤษที่ความหมายตรงกัน:
- headline: ประโยคเดียวที่สรุปสิ่งสำคัญที่สุดของรอบนี้ เริ่มด้วยตัวอย่างหัวข้อจริงจากข้อเท็จจริง
- bullets: 3–5 ข้อ ข้อละประโยคสั้นประโยคเดียว เริ่มด้วยตัวอย่างหัวข้อ แล้วตามด้วยตัวเลข (หัวข้อกำลังเกิดใหม่ หัวข้อกำลังมาแรง หัวข้อที่ลดลง และข้อจำกัดของข้อมูลถ้ามี)

กติกา:
- ตัวเลขทุกตัวต้องมาจากข้อเท็จจริงข้างต้น (ปัดเศษได้) ห้ามคำนวณตัวเลขใหม่ ห้ามแปลงปีเป็น พ.ศ.
- ถ้าบอกการเปลี่ยนแปลงต่อปี ให้บอกด้วยว่าน่าจะอยู่ระหว่างเท่าไรถึงเท่าไร
- เอ่ยชื่อหัวข้อได้เฉพาะชื่อที่อยู่ในข้อเท็จจริง ห้ามเดาสาเหตุ ห้ามใช้คำฟุ่มเฟือย ไม่ต้องใส่เลขลำดับหน้าข้อ

ภาษาและน้ำเสียง (ผู้อ่านคือประชาชนทั่วไป):
- ใช้ภาษาง่าย ประโยคสั้น ประโยคละหนึ่งเรื่อง เหมือนอธิบายให้คนทั่วไปฟัง ไม่ใช่ภาษารายงานสถิติ
- ตัวเลขทุกตัวมีหน่วยกำกับ (บทความ วารสาร สถาบัน % ต่อปี) และบอกช่วงเวลาเป็นปีจากข้อเท็จจริง (คำว่า "ปี" ตามด้วยช่วงปี) แทนคำว่า "ช่วงฐาน" หรือ "ช่วงล่าสุด"
- เรียกสถานะด้วยชื่อไทยในข้อความภาษาไทย (กำลังเกิดใหม่ จับตา กำลังมาแรง ลดลง คงที่ ข้อมูลน้อย) และชื่ออังกฤษในข้อความภาษาอังกฤษ (Emerging, Watch, Hot, Declining, Stable, Low data) ห้ามใช้รหัสตัวพิมพ์ใหญ่ เช่น EMERGING หรือ LOW_DATA
- ห้ามใช้ศัพท์สถิติหรือศัพท์เทคนิคเหล่านี้: ช่วงเชื่อมั่น, ช่วงฐาน, ช่วงล่าสุด, ฐานเปรียบเทียบ, เกณฑ์ความกว้าง, นัยสำคัญ, มัธยฐาน, ผู้แต่ง, confidence interval, CI, baseline, breadth test, HHI, subfield, Jaccard, Jensen–Shannon, cosine, metadata, embedding, c-TF-IDF — ถ้าต้องบอกความไม่แน่นอนของตัวเลข ให้เขียนว่า "น่าจะอยู่ระหว่าง ... ถึง ..." (ภาษาอังกฤษ "likely between ... and ...")

ตอบกลับเป็น JSON เท่านั้น ห้ามมีข้อความอื่น:
{
  "headline_th": "ประโยคสรุปภาษาไทย",
  "headline_en": "The headline in English",
  "bullets_th": ["ข้อที่หนึ่ง", "ข้อที่สอง", "ข้อที่สาม"],
  "bullets_en": ["First point", "Second point", "Third point"]
}
```
