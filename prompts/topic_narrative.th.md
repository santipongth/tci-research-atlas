# Prompt: คำอธิบายหัวข้อจากตัวเลขของ pipeline (topic narrative)

> **สถานะ: ใช้งานจริง — ไฟล์นี้คือต้นฉบับเดียว** `pipeline/atlas/narrative.py` อ่าน block ใต้ "Prompt (master)" ตอนรัน (งาน LLM `narrative`)
> แก้ข้อความใน block = `prompt_version` เปลี่ยน → คำอธิบายถูกเขียนใหม่ในรอบถัดไป; แก้หมายเหตุนอก block ไม่มีผลต่อ cache
> (เดิมชื่อ `emerging_narrative.th.md` — ออกแบบไว้ใน P0 แต่ยังไม่เคยใช้)

## บริบทการใช้

- เรียกต่อหัวข้อ เฉพาะ `narrative.top_n` หัวข้อแรกของแต่ละสถานะใน `narrative.statuses` (EMERGING / WATCH / HOT เรียงตาม emerging_score, DECLINING เรียงตามอัตราลดลง)
- inputs: `{facts}` = ข้อเท็จจริงจาก pipeline (ชื่อ สถานะ สัดส่วนช่วงฐาน→ช่วงล่าสุด อัตราเปลี่ยนพร้อมช่วงเชื่อมั่น จำนวนบทความ/วารสาร/สถาบัน พยากรณ์เมื่อผ่านเกณฑ์ skill) · `{titles}` = ชื่อบทความตัวแทน (บรรทัดละ 1 เรื่อง)
- **ตรวจหลังได้คำตอบ** (`narrative.grounding_error`): ตัวเลขทุกตัวต้องอยู่ใน `{facts}` (ปัดเศษ 0–1 ตำแหน่งได้, เลขไทยแปลงก่อนตรวจ) และห้ามมีชื่อหัวข้ออื่น → ไม่ผ่าน = ให้เขียนใหม่ `llm.max_regenerations` ครั้งพร้อมบอกเหตุผล → ไม่ผ่านอีก = ใช้ประโยคแม่แบบจากตัวเลขชุดเดียวกัน (`source: template`)
- ผลลัพธ์ → `work/11_narratives` → `topics/<id>.json → narrative` (เว็บแสดงพร้อมป้าย "สรุปอัตโนมัติจากตัวเลขของระบบ")
- หัวข้อใหม่ที่ไม่มีบทความในปีก่อน: facts เขียนว่า "ไม่มีปีก่อนให้เทียบ" และไม่มีจำนวนเท่า — prompt สั่งไม่ให้เขียนเป็นจำนวนเท่า
- น้ำเสียง (ตั้งแต่ web refresh 2026-10-23): ภาษาง่ายสำหรับประชาชนทั่วไป เริ่มด้วยตัวอย่าง ชื่อสถานะภาษาไทย ห้ามศัพท์สถิติตามรายการใน prompt — facts เขียนด้วยถ้อยคำเดียวกัน (`narrative.topic_facts`)

## Prompt (master)

```
คุณคือนักวิเคราะห์นโยบายวิจัย เขียนคำอธิบายสั้นของหัวข้อวิจัยหนึ่งหัวข้อให้ประชาชนทั่วไป ผู้บริหาร และบรรณาธิการวารสารอ่านเข้าใจ

ข้อเท็จจริงจากระบบ (ใช้ได้เฉพาะข้อมูลนี้):
{facts}

ตัวอย่างชื่อบทความในหัวข้อนี้:
{titles}

เขียน 2–3 ประโยค เป็นภาษาไทยและภาษาอังกฤษที่ความหมายตรงกัน โดย:
1. เริ่มด้วยตัวอย่าง: บอกว่าหัวข้อนี้เกี่ยวกับอะไร โดยยกตัวอย่างงานจริง 1 เรื่องจากตัวอย่างชื่อบทความ เช่น "งานอย่าง ..." (ใช้ชื่อ คำสำคัญ และตัวอย่างบทความ)
2. บอกทิศทางจากตัวเลข เลือก 1–2 ตัวเลขที่สำคัญที่สุด ถ้าบอกการเปลี่ยนแปลงต่อปี ให้บอกด้วยว่าน่าจะอยู่ระหว่างเท่าไรถึงเท่าไร
3. ถ้าข้อเท็จจริงบอกว่าเป็นหัวข้อใหม่ที่ไม่มีปีก่อนให้เทียบ ให้บอกตรง ๆ ว่าเป็นหัวข้อใหม่ ปีก่อนยังไม่มีบทความเรื่องนี้ ห้ามเขียนเป็นจำนวนเท่า

ภาษาและน้ำเสียง (ผู้อ่านคือประชาชนทั่วไป):
- ใช้ภาษาง่าย ประโยคสั้น ประโยคละหนึ่งเรื่อง เหมือนอธิบายให้คนทั่วไปฟัง ไม่ใช่ภาษารายงานสถิติ
- ตัวเลขทุกตัวมีหน่วยกำกับ (บทความ วารสาร สถาบัน % ต่อปี) และบอกช่วงเวลาเป็นปีจากข้อเท็จจริง (คำว่า "ปี" ตามด้วยช่วงปี) แทนคำว่า "ช่วงฐาน" หรือ "ช่วงล่าสุด"
- เรียกสถานะด้วยชื่อไทยในข้อความภาษาไทย (กำลังเกิดใหม่ จับตา กำลังมาแรง ลดลง คงที่ ข้อมูลน้อย) และชื่ออังกฤษในข้อความภาษาอังกฤษ (Emerging, Watch, Hot, Declining, Stable, Low data) ห้ามใช้รหัสตัวพิมพ์ใหญ่ เช่น EMERGING หรือ LOW_DATA
- ห้ามใช้ศัพท์สถิติหรือศัพท์เทคนิคเหล่านี้: ช่วงเชื่อมั่น, ช่วงฐาน, ช่วงล่าสุด, ฐานเปรียบเทียบ, เกณฑ์ความกว้าง, นัยสำคัญ, มัธยฐาน, ผู้แต่ง, confidence interval, CI, baseline, breadth test, HHI, subfield, Jaccard, Jensen–Shannon, cosine, metadata, embedding, c-TF-IDF — ถ้าต้องบอกความไม่แน่นอนของตัวเลข ให้เขียนว่า "น่าจะอยู่ระหว่าง ... ถึง ..." (ภาษาอังกฤษ "likely between ... and ...")

กติกา:
- ตัวเลขทุกตัวต้องมาจากข้อเท็จจริงข้างต้น (ปัดเศษได้) ห้ามคำนวณตัวเลขใหม่ ห้ามแปลงปีเป็น พ.ศ.
- ห้ามเอ่ยชื่อหัวข้ออื่น ห้ามเดาสาเหตุที่ข้อมูลไม่ได้บอก ห้ามใช้คำฟุ่มเฟือย เช่น "น่าสนใจ" "สำคัญมาก"

ตอบกลับเป็น JSON เท่านั้น ห้ามมีข้อความอื่น:
{
  "th": "คำอธิบายภาษาไทย",
  "en": "The same explanation in English"
}
```
