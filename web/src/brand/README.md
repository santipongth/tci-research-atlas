# แบรนด์ TCI (brand)

ทุกอย่างที่เกี่ยวกับแบรนด์อยู่ที่นี่จุดเดียว

- ตอนนี้ใช้ **wordmark ชั่วคราว** (กล่อง "TCI" + ชื่อ "TCI Research Atlas") — ไม่เลียนแบบโลโก้ TCI
- เมื่อได้โลโก้ทางการ: วางไฟล์ใน `src/brand/assets/` แล้วแก้ `brand.ts` ตามคอมเมนต์ (import ไฟล์ + ใส่ `logo` + `temporary: false`)
  Vite จะใส่ hash ให้ไฟล์ในเว็บ และฝังเป็น data URI ในไฟล์ HTML เดี่ยวให้เอง — ไม่ต้องแก้ไฟล์อื่น
- ข้อความ "เครื่องหมายชั่วคราว รอโลโก้ทางการของ TCI" ในส่วนท้ายเว็บจะหายไปเองเมื่อ `temporary: false`
- สี/ตัวอักษรของแบรนด์อยู่ใน `DESIGN.md` (root) และ `src/styles/tokens.css`
